# STRIDE 2027

## Local preview

From the project directory, run:

```sh
python3 -m http.server 8000
```

Open http://localhost:8000. Stop the server with Ctrl+C.

## Structure

- `index.html`: workshop overview and call for papers
- `organizers/index.html`: organizer biographies and university profiles
- `program_committee/index.html`: program committee members
- `schedule/index.html`: program linked from the homepage
- `css/main.css`: shared styling, including layout classes
- `img/`: workshop logo and favicon
